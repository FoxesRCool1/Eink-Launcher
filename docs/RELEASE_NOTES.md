# Release notes

## 0.2.0

- Icons, round shapes, landscape, split screen, app folders, new Settings

## 0.1.0

The first release.

- Today: date, time, the four tabs, a status line, the next routine item and
  a quick note.
- Read: a library of EPUB and PDF files. Highlights, typed notes and
  handwritten note cards in EPUB. Pen and marker straight on PDF pages.
- Write: folders, typed Markdown notes and handwritten notebooks. Export to
  PDF and PNG.
- Journal: one entry a day, typed or handwritten. Habits with streaks. A
  routine for the day.
- Apps: up to eight pinned apps, all apps from A to Z, and fixed entries for
  the ViWoods settings and the stock launcher.
- Everything you make is a plain file in one folder on the tablet.

Install guide: see `README.md`.
